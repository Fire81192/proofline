# 考卷

测一件事：**引文定位准不准。**

不是测「代码有没有崩」——那是 522 个测试的活。考卷测的是**准度**。

```
node tools/exam/run.mjs
```

---

## 两类题

**正题（44）**：从四库真实数据里抽的、**已经通过校验**的引文 + 它的快照。期望「能定位到」。

**负题（17）**：
- 13 条是把正题引文中间一个字换成「的」（最常见的字，最容易碰巧命中原文别处）
- 4 条是手工造的边界：顺序颠倒、跨句拼凑、多加一个字、少一个字

**为什么负题比正题重要：**

> 正题不中，是「该收的被拒了」——用户会抱怨，能发现。
> 负题中了，是「不该收的收了」——**没人会抱怨，错误就这么进了库**。

---

## 三个指标

| 指标 | 含义 | 门 |
|---|---|---|
| `recall` | 正题里有多少能定位到 | ≥ 基线 − 0.05 |
| `falsePositive` | 负题里有多少被误判命中 | **必须为 0** |
| `degraded` | 生成时是 exact、现在降级了的条数 | **必须为 0** |

**误报的门是 0，不是「尽量少」。**

一个「偶尔把改过的字当成原文」的工具，会让整条证据链的可信度变成零——因为你没法知道哪几条是那种情况。

**误报不是「质量下降」，是「这个工具的前提不成立了」。**

### 为什么还要测级别退化

**这一条是实测逼出来的。**

把 `locateQuote` 的一级匹配（`indexOf`）人为弄坏，44 条正题**仍然全中**：

```
正题 44：命中 44（100.0%）
  normalized 36 · space-insensitive 8      ← exact 全没了
判定：通过                                     ← 考卷没抓到
```

**因为降级匹配把全部救回来了。**

结果是「中了」，但引文的严谨度已经下降：本来逐字可核的，变成了「折叠空白、甚至去掉全部空白之后才核到」。

**对一个以「逐字」为信条的工具，这是实质退化，不是等价替换。**

所以题库里每条正题都带一个 `expectMode`（生成那一刻的级别），
跑分时**实际级别不许比它更松**。补上之后，同样的破坏会判「不通过（级别退化）」，退出码 1。

---

## recall 100% 是什么意思（重点）

**基线是 1.000。但别把它读成「定位准确率 100%」。**

这 44 条正题是从**已经通过校验的条目**里抽的。它们能过，是因为当初真定位到了。

**所以 recall 100% 是预期内的，它证明的是「没退」，不是「准」。**

考卷的真正价值在**回归**：

```
改了 quote.js → 这 44 条还能不能全中？那 17 条还能不能零误报？
```

**改坏了会立刻掉下来，这是它唯一能保证的事。**

要测「绝对准确性」，需要一份**独立的、人工标注的**引文数据集——目前没有。
`questions.jsonl` 里的 13 条真实负题是「真实引文的破坏版」，它们有绝对意义（真的不该中）；
但它们是从同一批数据派生的，覆盖面有限。

**这条限制写在前面，免得有人拿 recall 1.000 去证明什么。**

---

## 为什么这里不测数值边界

试过，造错了。

```
1.5 在 1.5-2.0 里   → 定位成功
1.5 在 1.5.0 里     → 定位成功
```

因为 `1.5` 确实是连续子串。

**两套规则不一样：**

| 函数 | 管什么 | 1.5 在 1.5-2.0 里 |
|---|---|---|
| `locateQuote` | 原文有没有这段**连续的字** | **该中**（它是连续片段） |
| `containsValue` | 这个**数**是不是独立的 | **不该中**（1.5 和 1.52 不是同一个数） |

引文定位和数值匹配是两件事。**混在一起考，测出来的不是任何一个。**

---

## 题库是冻结的

`questions.jsonl` 由 `build.mjs` 从四库生成，**改 `quote.js` 之后如果过不了，不许改题。**

**只能改代码。**

否则就是「改考题让它及格」——那是这个考卷唯一防不住的东西，因为它防不住自愿。

---

## 加题

**加真实题**：往四库添加新条目，重跑 `node tools/exam/build.mjs`。

**加合成题**：改 `build.mjs` 里的 `SYNTHETIC` 数组。

脚本会自检每条合成题：
- 负题必须不中，中了就警告并丢弃（说明题造错了）
- 正题必须中，不中就警告并丢弃

**这条自检救过一次**——`1.5` 那两条就是这么被拦下来的。
